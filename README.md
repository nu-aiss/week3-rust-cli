# Week 3 — Rust CLI
## Цель
Целью задания было создать небольшую CLI-программу на Rust и использовать основные конструкции языка, которые пригодятся при дальнейшем изучении Solana.

## Что делает программа
Программа принимает три значения:
- адрес отправителя;
- адрес получателя;
- количество SOL.
После запуска программа выводит информацию о переводе.
Также программа проверяет, чтобы сумма перевода была больше нуля.

## Использованные конструкции Rust
В программе были использованы:
- `struct`
- `enum`
- `impl`
- функции
- `Result`
- `match`
- аргументы командной строки

## Структура программы
Для хранения информации о переводе используется структура `Transfer`.
Она содержит:
- `from` - адрес отправителя;
- `to` — адрес получателя;
- `amount` — сумма перевода;
- `network` — сеть Solana.
Для сети используется `enum Network`, где указана сеть `Devnet`.

## Пример запуска
Команда:
```bash
cargo run -- transfer Alice Bob 0.5
```

Результат:
```text
Transfer created successfully!
From: Alice
To: Bob
Amount: 0.5 SOL
Network: Devnet
```

## Проверка ошибки
Также я проверила работу программы с неправильной суммой.
Команда:
```bash
cargo run -- transfer Alice Bob -1
```

Результат:
```text
Error: Amount must be greater than 0.
```
Таким образом, программа не принимает отрицательную сумму и выводит сообщение об ошибке.
